# RiderSafe AI

**Report together. Navigate smarter. Ride safer.**

A multilingual, community-powered navigation and safety app concept for international food-delivery riders in Melbourne (ADA5111 final prototype concept).

The site includes:
- The concept, value proposition and primary user
- Five core features and the seven-step reporting loop
- The seven-screen prototype storyboard
- A clickable live prototype (English, 简体中文, 繁體中文, 日本語) with spoken audio alerts
- Stakeholder value, the Melbourne CBD pilot, testing plan, key hypothesis and next steps

## View the site
Enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root). The site will be published at
`https://<your-username>.github.io/ridersafe-ai/`.

The whole site is a single self-contained `index.html` with no build step.
