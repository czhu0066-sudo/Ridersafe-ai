# RiderSafe AI

**Report together. Navigate smarter. Ride safer.**

A multilingual, community-powered navigation and safety app concept for international food-delivery riders in Melbourne (ADA5111 final prototype concept).

The site opens straight into the app prototype, one screen at a time, because riders on the road have little attention to spare:

1. Welcome: choose language (English, 简体中文, 繁體中文, 日本語) and audio alerts
2. Navigation map with one large "Report road condition" button
3. Report: only three colours (Danger / Lane blocked / Congestion)
4. Confirmation on the map
5. Alert for a nearby rider (spoken in the chosen language)
6. Community verification
7. Updated map with a safer route

The concept, features, pilot and hypothesis come last, on the About screen.
